## 📊 Dataset

- **Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/breast+cancer+wisconsin+(diagnostic))
- **Features:** 30 numerical features from digitised images of breast masses
- **Target:** 
  - 0 = Malignant
  - 1 = Benign

---

## ✅ Objectives

- Load and preprocess the dataset
- Apply Logistic Regression
- Evaluate model performance with:
  - Accuracy
  - Confusion Matrix
  - Precision, Recall, F1-score

---

## 🧠 Model Performance

The model performs excellently, achieving high precision and recall, meaning it correctly classifies most tumors with minimal false predictions.
